### ⬢ [Hydra](https://hydra.uvansa.com)

[![site](https://img.shields.io/badge/hydra.uvansa.com-00ADD8?style=flat-square&labelColor=161b22)](https://hydra.uvansa.com)

**One CLI for every model on your machine.**

Finds 13+ CLI tools, 14 API providers and every local server in **under 2 seconds**, then routes by capability, cost, and a sequential probability ratio test for *confidence of correctness* — not just whichever model is cheapest. PII is blocked at the dispatch layer, before it ever leaves the machine.

`~1.1µs` routing overhead · `75–85%` cheaper than going all-frontier

```bash
brew install ankit373/hydra/hyctl
```
